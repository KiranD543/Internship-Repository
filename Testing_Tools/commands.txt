Prokka: 

To put all the fasta files, downloaded from NCBI in one directory:
$ cp ~/ncbi_dataset/data/GCF_*/*.fna ~/prokka_test/

To perform annotation:
$ for fasta in ~/prokka_test/*.fna; do
	strain=$(basename $fasta.fna)
	echo "Annotating: $strain"
	prokka --outdir prokka_output/$strain \
		--prefix $strain \
		--genus Lactiplantibacillus \
		--species plantarum \
		--kingdom Bacteria \
		--cpus 4 \
		$fasta
done

PPanGGOLiN:
The location of the gff files needs to be put into a tab delimited file with the following code:
$ for gff in prokka_gff_output/*gff; do
strain=$(basename $gff .gff)
echo -e "$strain\t$(realpath $gff)"
done > ppanggolin_input.tsv

To run the analysis:
$ ppanggolin workflow \
--anno ppanggolin_input.tsv \
--output ppanggolin_output \
--cpu 4

To open the interacive U-curve (or tile-plot):
$ xdg-open Ushaped_plot.html

Anvio: 
To reformat the fasta files: 
$ for fasta in test_fastas/*.fna; do 
> strain=$(basename $fasta .fna) 
> echo "Reformatting: $strain" 
> docker run --rm -v ~/anvio_test:/data meren/anvio:latest \ 
> anvi-script-reformat-fasta \ 
> /data/test_fastas/$strain.fna \ 
> -o /data/test_fastas/${strain}_reformatted.fna \ 
> --simplify-names 
> done 

To create a contigs database per strain:
$ for fasta in test_fastas/*_reformatted.fna; do 
> strain=$(basename $fasta _reformatted.fna) 
> echo "Processing: $strain" 
> docker run --rm -v ~/anvio_test:/data meren/anvio:latest \ 
> anvi-gen-contigs-database \ 
> -f /data/test_fastas/${strain}_reformatted.fna \ 
> -o /data/$strain.db \
> -n $strain 
> done 

To run HMMs on each database:
$ for db in ~/anvio_test/*.db; do 
> strain=$(basename $db .db) 
> echo "Running HMMs: $strain" 
> docker run --rm -v ~/anvio_test:/data meren/anvio:latest \ 
> anvi-run-hmms \ 
> -c /data/$strain.db
> done 

To make the genomes.txt file:
$ echo -e "name\tcontigs_db_path" > genomes.txt 
$ for fasta in test_fastas/*_reformatted.fna; do 
> strain=$(basename $fasta _reformatted.fna) 
> echo -e "$strain\t/data/$strain.db" 
> done >> genomes.txt 

To make a genome storage: 
$ docker run --rm -v ~/anvio_test:/data meren/anvio:latest \ 
> anvi-gen-genomes-storage \ 
> -e /data/genomes.txt \ 
> -o /data/Lactiplantibacillus-GENOMES.db 

To run the pangenome analysis: 
$ docker run --rm -v ~/anvio_test:/data meren/anvio:latest \ 
> anvi-pan-genome \ 
> -g /data/Lactiplantibacillus-GENOMES.db \ 
> -o /data/pangenome_output \ 
> -n Lactiplantibacillus_plantarum \ 
> --num-threads 4 

To visualize the pangenome: 
$ docker run --rm -p 8080:8080 -v ~/anvio_test:/data meren/anvio:latest \ 
> anvi-display-pan \ 
> -g /data/Lactiplantibacillus-GENOMES.db \ 
> -p /data/pangenome_output/Lactiplantibacillus_plantarum-PAN.db
